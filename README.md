# OFFFEED: Your Style Escape

Build a modern, aesthetic, interactive website called OFFFEED.

✨ Brand Concept

OFFFEED is a fashion discovery platform for people who are tired of seeing the same repetitive trends on Instagram and Pinterest. It helps users discover unique outfits, aesthetics, styling ideas, and fashion inspiration that feels personal rather than algorithmically repetitive.

The overall feeling should be:
Pinterest meets Instagram meets a premium fashion magazine — but softer, more personal, and Gen-Z.

🎀 Visual Style

Use a soft pink background as the main website color.

Color palette:

Main background: soft blush pink / pastel pink

Secondary background: very light pink / almost-white pink

Text: deep chocolate brown or soft black

Accent: slightly darker rose pink

Cards: cream, white, and very subtle pink

Buttons: elegant rose/pink tones

Do NOT make the website look overly childish, Barbie-themed, or neon pink.

The aesthetic should feel:
soft + cool + premium + feminine + minimal + Gen-Z.

Use plenty of whitespace, rounded corners, subtle shadows, smooth animations, elegant typography, and editorial-style fashion imagery.
